# Главное меню

Сцена: `Assets/Scenes/MainMenu.unity`. Открыть из Project или через **Hakaton → Главное меню → Создать или открыть**, затем нажать Play. Сцена установлена первой в Build Settings.

Кабинет собран в Unity по композиции присланного изображения: стол на переднем плане, материалы дела, пистолет, пепельница и кружка; окна с жалюзи слева; картотека, доски и часы сзади; открытая дверь и сотрудники участка справа. Столы, кресло, шкафы, телефон, оружие, сотрудники и материалы взяты из проекта. Дополнительные детали выполнены той же простой геометрией. Фон снимает настоящая камера. Вентилятор и секундная стрелка вращаются, дым создаёт ParticleSystem, а ламели отбрасывают тени на кабинет.

- **Новая игра** — начинает новое расследование: полное вступление Frank’s Choice, затем HouseArrival. Esc пропускает вступление.
- **Вступление** — просмотр того же ролика; после окончания или по Esc открывается главное меню.
- **Настройки** — общая громкость и чувствительность мыши. Значения сохраняются через PlayerPrefs и применяются в игре; Esc закрывает панель.
- **Выход** — завершает приложение; в редакторе останавливает Play.

В игре возврат доступен через **Esc → Главное меню**. Интерфейс работает мышью и стандартной навигацией клавиатуры. Настройки открываются поверх продолжающей жить сцены.

Для изменения композиции редактируйте пронумерованные группы объекта «ГЛАВНОЕ МЕНЮ · кабинет детектива». «Камера кабинета» задаёт ракурс. MenuAtmosphere управляет вентилятором, секундной стрелкой, небольшим движением камеры и тихой вентиляцией. Материал MenuGrade отвечает за тёплый цвет и лёгкую ретро-обработку; RetroView задаёт разрешение фонового рендера. Титры и кнопки остаются чёткими поверх него. Генератор открывает существующую сцену, сохраняя ручную работу.

Автоматическая проверка: `AgentScripts/VerifyMainMenu.cs`, результат — `Docs/main-menu-verification.txt`. Проверены живой фон, анимации, тени, доступность кнопок, ввод ползунка мышью, сохранение параметров, оба маршрута вступления и возврат из паузы. Итоговый игровой кадр — `Docs/main-menu.png`.
